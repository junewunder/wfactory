# Overseeing this factory

The overseer's guide lives in the wfactory skill, not here: run
`just oversee-guide` to read its card, and `just oversee-guide --full` for the
whole guide (the skill's `runtime/oversee-card.md` and `runtime/oversee.md`,
in the copy `factory/skill` picks). This project's own additions are in
`factory/oversee.local.md`, if it has one.
